# 02. 회원가입 추가정보 입력 흐름

---

## 전체 흐름 요약

```
카카오 로그인 (isNewUser: true)
    → 닉네임 중복 확인 (선택)
    → 추가정보 입력 (닉네임, 성별, 나이, 지역, 종목, 실력, 포지션)
    → POST /api/members/signup/complete
    → 완료
```

---

## 1. 닉네임 중복 확인

### API
```
GET /api/members/check-nickname?nickname=홍길동
인증 불필요
```

### 서버 처리
```
1. MemberRepository.existsByNickname(nickname) 조회
2. 결과 반환
   └─ available: true  → 사용 가능
   └─ available: false → 이미 사용 중
```

### 응답
```json
// 사용 가능
{ "success": true, "message": "사용 가능한 닉네임입니다", "data": { "available": true } }

// 중복
{ "success": true, "message": "이미 사용 중인 닉네임입니다", "data": { "available": false } }
```

> `success`는 항상 `true`입니다. 사용 가능 여부는 `data.available`로 판단하세요.

---

## 2. 회원가입 완료 (추가정보 입력)

### API
```
POST /api/members/signup/complete
Authorization: Bearer {accessToken} 필요
```

### 요청
```json
{
  "nickname": "홍길동",
  "gender": "M",
  "age": 22,
  "address": "서울시 노원구 신부동",
  "latitude": 37.6394,
  "longitude": 127.0722,
  "favoriteSports": ["SOCCER", "BASKETBALL"],
  "skillLevel": "INTERMEDIATE",
  "preferredPosition": "ST"
}
```

### 필수/선택 필드
| 필드 | 필수 | 검증 |
|------|------|------|
| `nickname` | ✅ | 2~10자, `@NotBlank` |
| `gender` | ✅ | `@NotBlank` (M/F) |
| `age` | ✅ | `@NotNull` |
| `favoriteSports` | ✅ | `@NotNull`, 1개 이상 |
| `address` | ❌ | - |
| `latitude`, `longitude` | ❌ | - |
| `skillLevel` | ❌ | null이면 서버에서 "BEGINNER"로 기본값 설정 |
| `preferredPosition` | ❌ | - |

### 서버 내부 처리 순서

```
1. JWT에서 memberId 추출 → DB에서 Member 조회
   → 없으면 404 (USER_NOT_FOUND)

2. 이미 signupCompleted == true인지 확인
   → 이미 완료됐으면 409 (SIGNUP_ALREADY_COMPLETED)

3. 닉네임 중복 확인
   → DB에 동일 닉네임 존재하면 409 (NICKNAME_ALREADY_EXISTS)

4. Member 필드 업데이트 (member.completeSignup())
   → nickname, gender, age, address, latitude, longitude, skillLevel, preferredPosition
   → signupCompleted = true 로 변경

5. favoriteSports 업데이트
   → 기존 목록 clear() 후 새 목록 addAll()
   → favorite_sport 테이블에 저장

6. 변경된 Member 반환 (MemberDTO)
```

### 응답
```json
{
  "success": true,
  "message": "회원가입이 완료되었습니다",
  "data": {
    "memberId": 2,
    "nickname": "홍길동",
    "gender": "M",
    "age": 22,
    "address": "서울시 노원구 신부동",
    "skillLevel": "INTERMEDIATE",
    "favoriteSports": ["SOCCER", "BASKETBALL"],
    "signupCompleted": true,
    "role": "USER"
  }
}
```

### 에러
| 상황 | HTTP | 에러코드 |
|------|------|---------|
| 이미 가입 완료된 계정 | 409 | `SIGNUP_ALREADY_COMPLETED` |
| 닉네임 중복 | 409 | `NICKNAME_ALREADY_EXISTS` |
| 필수 필드 누락 | 400 | Bean Validation 메시지 |
| 회원 없음 | 404 | `USER_NOT_FOUND` |

## DB 구조 참고

### member 테이블 (핵심 필드)
```
member_id        BIGINT (PK)
kakao_id         BIGINT (카카오 고유 ID)
email            VARCHAR (unique)
nickname         VARCHAR (unique, 가입 후 채워짐)
gender           VARCHAR
age              INT
address          VARCHAR
latitude         DOUBLE
longitude        DOUBLE
skill_level      VARCHAR
preferred_position VARCHAR
role             VARCHAR (기본: "USER")
signup_completed BOOLEAN (기본: false → 완료 후 true)
created_at       DATETIME
updated_at       DATETIME
```

### favorite_sport 테이블
```
member_id  BIGINT (FK → member.member_id)
sport_type VARCHAR (예: "SOCCER", "BASKETBALL")
```

> `favoriteSports`는 `@ElementCollection`으로 별도 테이블에 저장됩니다.
