# 09. 알림 흐름

---

## 전체 흐름 요약

```
앱 실행 시      → POST /api/devices/token        (FCM 푸시 토큰 등록)
알림 목록 확인  → GET  /api/notifications         (Cursor 페이지네이션)
배지 카운트     → GET  /api/notifications/unread-count
알림 읽음 처리  → PATCH /api/notifications/{id}/read
전체 읽음       → PATCH /api/notifications/read-all
알림 삭제       → DELETE /api/notifications/{id}
알림 설정 조회  → GET  /api/notifications/settings
알림 설정 변경  → PATCH /api/notifications/settings
```

---

## 1. FCM 푸시 토큰 등록/갱신

### API
```
POST /api/devices/token
Authorization: Bearer {accessToken} 필요
```

### 요청
```json
{
  "token": "fcm_device_token_string...",
  "platform": "ANDROID"
}
```

> `platform`: `ANDROID` | `IOS` | `WEB`

### 서버 처리
```
1. 같은 토큰이 이미 DB에 있는지 확인
   └─ 있고 다른 사용자 것이면 → 현재 사용자로 owner 변경
   └─ 현재 사용자 것이면 → 그대로 유지

2. 없으면 새로 저장

3. 성공 응답
```

> **앱 재설치나 로그아웃 시 FCM 토큰이 바뀔 수 있으므로 매 앱 실행 시 호출이 권장됩니다.**

---

## 2. FCM 푸시 토큰 삭제

### API
```
DELETE /api/devices/token?token=fcm_token_string...
Authorization: Bearer {accessToken} 필요
```

> 로그아웃 시 호출하지 않으면 다른 사용자가 이 기기로 로그인했을 때  
> 이전 사용자의 알림이 발송될 수 있습니다.

---

## 3. 알림 목록 조회

### API
```
GET /api/notifications?cursor=145&size=20&onlyUnread=false
Authorization: Bearer {accessToken} 필요
```

### 파라미터
| 파라미터 | 필수 | 기본값 | 설명 |
|---------|------|--------|------|
| `cursor` | ❌ | - | 이전 응답의 `nextCursor` (첫 요청 시 생략) |
| `size` | ❌ | 20 | 한 번에 가져올 개수 |
| `onlyUnread` | ❌ | false | true이면 안 읽은 알림만 조회 |

### Cursor 페이지네이션
```
첫 요청: cursor 없이 → 최신 20개 반환
다음 요청: cursor=144 → notificationId < 144인 것 중 최신 20개
nextCursor == null → 마지막 페이지
```

### 알림 타입 (noticeType)
| 타입 | 발생 시점 |
|------|----------|
| `MATCH_FOUND` | 매칭 성사 / 참가 수락 |
| `APPLICATION_REJECTED` | 참가 거절 |
| `MATCH_REMINDER` | 경기 시작 1시간 전 |
| `MATCH_CANCELLED` | 주최자가 경기 취소 |
| `RATING_REQUEST` | 경기 종료 후 칭찬 요청 |
| `SYSTEM_NOTICE` | 시스템 공지 |

### 응답
```json
{
  "success": true,
  "message": "알림 목록 조회 성공",
  "data": {
    "items": [
      {
        "notificationId": 145,
        "noticeType": "MATCH_FOUND",
        "title": "매칭 성사!",
        "content": "백석대 컴공 내기 매칭이 성사되었습니다.",
        "isRead": false,
        "targetType": "MATCH",
        "targetId": 12,
        "createdAt": "2026-05-17T19:00:00"
      },
      {
        "notificationId": 144,
        "noticeType": "MATCH_REMINDER",
        "title": "경기 임박",
        "content": "오후 7시 '백석대 축구' 경기가 곧 시작됩니다.",
        "isRead": true,
        "targetType": "MATCH",
        "targetId": 1,
        "createdAt": "2026-05-17T18:00:00"
      }
    ],
    "nextCursor": 144
  }
}
```

> `targetType` + `targetId`를 이용해 알림 클릭 시 해당 경기 상세 페이지로 이동할 수 있습니다.

## 8. 알림 설정

### 조회
```
GET /api/notifications/settings
Authorization: Bearer {accessToken} 필요
```

### 응답
```json
{
  "success": true,
  "message": "알림 설정 조회 성공",
  "data": {
    "enabled": true,
    "updatedAt": "2026-05-17T18:30:00"
  }
}
```

### 변경
```
PATCH /api/notifications/settings
Authorization: Bearer {accessToken} 필요
```

```json
// 요청
{ "enabled": false }

// 응답
{
  "success": true,
  "message": "알림 설정이 변경되었습니다",
  "data": { "enabled": false, "updatedAt": "2026-05-17T19:01:00" }
}
```

> `enabled: false`이면 FCM 푸시 알림이 발송되지 않습니다.

## 알림 발송 구조

알림은 `NotificationTriggerService`가 담당합니다.

```
이벤트 발생 (경기 참가, 취소 등)
    → NotificationTriggerServiceImpl.trigger()
    → NotificationService.save() (DB 저장)
    → FcmPushService.send() (FCM 푸시 발송)
        └─ DeviceTokenRepository로 수신자의 FCM 토큰 조회
        └─ FCM API 호출
```

### 개발/테스트 환경
FCM 실제 발송 대신 `FcmPushServiceMock`이 사용되어 콘솔 로그만 출력합니다.

## DB 구조 참고

### notification 테이블
```
notification_id  BIGINT (PK)
member_id        BIGINT (수신자)
notice_type      VARCHAR (알림 타입)
title            VARCHAR
content          TEXT
is_read          BOOLEAN (기본: false)
is_deleted       BOOLEAN (기본: false)
target_type      VARCHAR (MATCH 등)
target_id        BIGINT
created_at       DATETIME
```

### device_token 테이블
```
token_id   BIGINT (PK)
member_id  BIGINT (소유자)
token      VARCHAR (FCM 토큰, unique)
platform   VARCHAR (ANDROID / IOS / WEB)
created_at DATETIME
updated_at DATETIME
```

### notification_setting 테이블
```
member_id   BIGINT (PK)
enabled     BOOLEAN
updated_at  DATETIME
```
